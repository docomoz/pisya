# Pisa

**Рекордер встреч для Mac с локальной расшифровкой.** Записывайте разговоры, находите нужные фрагменты и сохраняйте текст в Markdown.

Pisa работает на Mac с Apple Silicon и macOS 15 или новее. Приложение находится на ранней стадии разработки.

![Окно Pisa с расшифровкой вымышленной встречи и списком записей](docs/images/transcript.png)

На скриншотах показана версия в разработке; оформление и отдельные команды могут отличаться от последнего релиза. Встречи и диалог вымышлены.

## Установка

### Из DMG

1. Скачайте `Pisa-<версия>-arm64.dmg` со [страницы последнего релиза на GitHub](https://github.com/docomoz/pisa/releases/latest).
2. Откройте образ и перетащите Pisa в папку «Программы».
3. Перед первым запуском откройте Терминал и снимите атрибут карантина с этой копии приложения. Выполняйте команду только для Pisa, скачанной со страницы релиза.

   ```sh
   xattr -dr com.apple.quarantine "/Applications/Pisa.app"
   ```

4. Запустите Pisa из папки «Программы».

Эта сборка подписана локально и пока не прошла нотариальную проверку Apple. В релизе есть файл `SHA256SUMS` для проверки скачанного образа.

### Через Homebrew

```sh
brew install --cask docomoz/tap/pisa
xattr -dr com.apple.quarantine "/Applications/Pisa.app"
```

При установке в другую папку укажите в команде путь к своей копии `Pisa.app`.

### Обновления

Пункт «Проверить обновления…» есть в меню Pisa и в разделе «Настройки → Обновления». Pisa проверяет подпись обновлений, полученных с GitHub. По умолчанию обновления загружаются автоматически и устанавливаются при выходе из Pisa. Автоматическую установку можно отключить в настройках.

Переходите с Pisya? [Скопируйте библиотеку встреч в Pisa](docs/migration.md).

## Возможности

- **Запись встреч.** Pisa записывает микрофон и системный звук на отдельные дорожки. Запись можно начать до звонка или во время разговора. Pisa работает с приложениями для звонков и браузерами. Вместе со звонком могут записаться и другие звуки Mac.
- **Расшифровка на Mac.** Распознавание речи и обработка звука выполняются локально. Во время встречи может появляться черновик; после записи Pisa обрабатывает оставшееся аудио. В словарь можно добавить имена и названия с нужным написанием.
- **Импорт аудио.** Можно расшифровать существующие записи, например M4A, WAV и MP3. Pisa копирует файл в библиотеку, а исходник остаётся на месте.
- **Участники.** Можно прослушать фрагменты, исправить имена и сохранить образцы голосов для следующих встреч.
- **Библиотека.** Записи можно искать, редактировать, раскладывать по папкам и восстанавливать из корзины.
- **Термины и названия.** Можно найти и переслушать фрагменты с нужным словом, исправить выбранные вхождения и сохранить написание в словарь.
- **Экспорт.** Сохраняйте расшифровку в Markdown или аудио встречи отдельным файлом. Автоэкспорт сохраняет текст, участников и временные метки в выбранную папку, например в хранилище Obsidian, и обновляет файл после правок.
- **Доступ через MCP.** Подключённый MCP-клиент, например ИИ-ассистент, может искать реплики вместе с соседними фрагментами, находить встречи по датам, участникам и папкам, читать расшифровки и узнавать состояние обработки. Ссылки на источники открывают нужный фрагмент в Pisa. MCP предоставляет доступ только для чтения, работает без сетевого порта и не передаёт аудиофайлы. Доступ включён по умолчанию и отключается в настройках.


## Приватность

Для записи нужны разрешения на доступ к микрофону и запись системного звука. Для захвата системного звука Pisa использует Core Audio taps и не запрашивает доступ к изображению экрана. При переходе с Pisya macOS запросит разрешения для Pisa отдельно.

Аудио и расшифровки хранятся на вашем Mac, распознавание тоже выполняется локально. Приложение работает в App Sandbox. Интернет нужен для загрузки моделей с Hugging Face и проверки обновлений на GitHub; для распознавания аудио и расшифровки никуда не отправляются.

Для подсчёта активных установок и использования функций Pisa отправляет обезличенную статистику в TelemetryDeck. В неё входят события запуска, записи, расшифровки и использования функций, длительность аудио, время события, хеш случайного идентификатора установки, версии Pisa и macOS. Аудио, тексты, названия, имена и пути не передаются. [Подробнее о статистике](docs/analytics.md).

Если выбрать папку, синхронизируемую через iCloud, Dropbox или другой сервис, экспортированные тексты могут попасть в облако. При использовании MCP подключённый клиент также может передать прочитанный текст своему провайдеру. Автоэкспорт включается выбором папки, а доступ MCP включён по умолчанию; подключение клиента настраивается отдельно.

Голосовые образцы хранятся отдельно от аудио встреч. Удаление аудио встречи не удаляет сохранённые образцы голосов. Отдельного пароля для библиотеки нет: её защита зависит от учётной записи macOS, прав файлов и FileVault.

## Сборка

Для сборки из исходников понадобятся Mac с Apple Silicon, macOS 15+, Xcode с Metal Toolchain, XcodeGen, Python 3.9 или новее и Node.js 24 для проверок сайта.

```sh
git clone --recurse-submodules https://github.com/docomoz/pisa.git
cd pisa
./scripts/build.sh
```

Сборка создаёт приложение `build/Build/Products/Release/Pisa.app` и оформленный установочный образ `build/Pisa-<версия>-arm64.dmg`. В образе есть приложение и ссылка на Applications. Нативные библиотеки, Metal-ресурсы и помощник MCP уже включены в приложение. Пользователю готовой сборки не нужны Xcode, Homebrew или Python.

Скрипт `scripts/build.sh` запускает полный Pretest перед сборкой установочного образа. Для небольших изменений локально проверяйте затронутое поведение. Полный прогон можно запустить отдельно:

```sh
python3 scripts/pretest.py
```

Полный прогон требует активной графической сессии macOS. Ошибка или недоступная обязательная проверка останавливает сборку. Логи и отчёт сохраняются в `build/pretest/`. GitHub Actions подбирает проверки по изменённым файлам. [Условия полного прогона и состав проверок](docs/pretest.md).

Если Metal Toolchain не установлен, его можно загрузить командой:

```sh
xcodebuild -downloadComponent MetalToolchain
```

Для запуска тестов ядра:

```sh
swift test
```

Регрессии интерфейса на macOS с графической сессией:

```sh
bash Tests/Native/run-interface-controls-test.sh
bash Tests/Native/run-interface-layout-test.sh /путь/к/Pisa.app
```

Первый тест использует общие элементы форм. Второй проверяет экраны
свежей сборки на вымышленных записях. Подробности в [проверках интерфейса](docs/interface-regressions.md).

Проверка словаря на синтезированной речи, тишине, шуме и эхе (после сборки и установки моделей; нужен русский голос Milena в macOS):

```sh
./Tests/Native/run-vocabulary-test.sh
```

Проверка распознавания русской речи на коротких ответах, длинных репликах, быстрой речи и словах из словаря, а также проверка на тишине и шуме для обоих каналов:

```sh
python3 Tests/Native/run-recognition-quality-test.py --output build/recognition-quality.jsonl
```

Проверка использует синтезированную речь и временные файлы; встречи в библиотеке не изменяются. Параметр `--corpus` позволяет передать собственные аудиопримеры с эталонным текстом для локального сравнения. Формат корпуса описан в скрипте.

По умолчанию используется локальная подпись приложения. После пересборки macOS может повторно запросить разрешения. [Порядок выпуска новой версии](docs/releasing.md).

## Начало работы

![Приветственный экран Pisa с кнопкой настройки](docs/images/welcome.png)

1. Нажмите «Загрузить модели» в окне первой настройки. Понадобится около 3 ГБ свободного места. Во время загрузки виден прогресс; её можно отменить и запустить снова. Уже проверенные файлы сохраняются, незавершённый файл загружается заново.
2. Нажмите «Начать запись» до начала звонка или во время разговора. Когда macOS попросит, разрешите доступ к микрофону и запись системного звука. Для начала проверьте работу на короткой встрече.
3. После обработки проверьте расшифровку и имена участников. При необходимости настройте экспорт в Markdown.

Настройку моделей можно отложить и вернуться к ней в разделе «Модель». Без моделей можно записывать и импортировать аудио. После установки моделей откройте запись и нажмите «Расшифровать». Можно использовать уже имеющуюся папку Qwen3-ASR; при необходимости Pisa загрузит модели участников и проверки русской речи. Скрипт `scripts/install-model.py` оставлен как дополнительный способ установки для разработчиков; подписанное приложение также поддерживает `Contents/MacOS/Pisa --install-models`.

Pisa не удаляет аудио автоматически. Удалить его можно вручную после проверки текста; при импорте исходный файл остаётся на месте.

## Что важно учитывать

- Распознавание и определение говорящих могут ошибаться, особенно если люди говорят одновременно или реплики очень короткие. Проверяйте расшифровку перед использованием.
- Автоматический запуск записи экспериментальный и по умолчанию выключен. Он ориентируется на использование микрофона другими приложениями, поэтому возможны ложные срабатывания.
- Эхоподавление зависит от микрофона, динамиков и условий записи. Исходные дорожки сохраняются.
- Доступ через MCP включён по умолчанию для новой установки. Доступны `list_meetings`, `search_meetings`, `read_transcript`, `list_folders` и `search_transcripts`. Поиск реплик работает по словам и фразам; MCP сообщает, что уверенность распознавания не измерялась, а полнота записи неизвестна. [Описание инструментов и пример запроса](docs/mcp.md). Отключить доступ можно в настройках. Если вы раньше отключили MCP, доступ останется выключенным после обновления.

## Технологии и зависимости

Приложение написано на Swift и SwiftUI. Для локального распознавания используются Qwen3-ASR и MLX Audio Swift; GigaAM-v3 через Sherpa ONNX помогает перепроверять русскую речь. Для обработки и разметки звука используются WebRTC AEC3, Silero VAD и Sherpa ONNX. Лицензии сторонних компонентов находятся рядом с соответствующими файлами. Веса моделей распространяются отдельно на условиях их авторов.
